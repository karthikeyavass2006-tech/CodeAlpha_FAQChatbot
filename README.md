# FAQ Chatbot

This is an AI-based FAQ Chatbot in which users can ask questions related to Artificial Intelligence, Machine Learning, Deep Learning, NLP, Computer Vision, and other AI topics. The chatbot processes the user's question and provides the most relevant answer using Natural Language Processing techniques.

## Project Overview:-

This project is the FAQ Chatbot, in which the user enters a question in the chat box and presses the send button. The chatbot analyzes the input text, compares it with stored frequently asked questions, and provides the best matching answer instantly.

## Features:-

- User-friendly and interactive GUI using Tkinter
- Natural Language Processing for understanding user queries
- Text preprocessing using:
  - Tokenization
  - Stopword removal
  - Lemmatization
- TF-IDF Vectorization for converting text into numerical form
- Cosine Similarity for finding the closest matching question
- Fast and accurate responses
- Scrollable chat interface
- Dark-themed chatbot design

## Tech Stack:-

- Python
- Tkinter module
- NLTK module
- Scikit-learn module
- TF-IDF Vectorizer
- Cosine Similarity Algorithm

## Functions:-

- Preprocessing user input text
- Removing unnecessary words and punctuation
- Converting text into vectors
- Comparing user questions with FAQ database
- Displaying chatbot responses
- Creating an interactive graphical user interface

## How user enters a question and gets an answer:-

1. User enters a question in the chatbot input box.
2. The chatbot preprocesses the entered text.
3. The question is converted into a vector using TF-IDF.
4. Cosine Similarity compares the question with available FAQ questions.
5. The chatbot displays the most relevant answer.

## Purpose:-

To provide a simple and user-friendly chatbot application that can answer frequently asked questions using Natural Language Processing and Machine Learning techniques.
